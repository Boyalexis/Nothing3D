# Q6 第二个小目标：对象复制与删除

> 后续更新：工程保存、打开和未保存提示已实现，见 [工程文件说明](Q6-files-learning.md)。下文保留本小目标完成时的记录。

本轮在模型页加入“复制对象”“删除对象”，复用上一轮的场景历史。两项操作各记录一步，可使用 Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做。

## 运行与验收

双击 `scripts/run.bat`，选中长方体或圆柱体，进入“模型 Model”页。

| 操作 | 入口 | 行为 |
| --- | --- | --- |
| 复制 | 复制对象；视口或场景列表内 Ctrl+D | 原位生成独立副本，追加到列表末尾并选中 |
| 删除 | 删除对象；视口或场景列表内 Delete | 删除所选对象并清空选择 |
| 撤销 / 重做 | 首页按钮；Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 恢复或重新应用一次操作 |

复制保留完整尺寸、位置和旋转，生成新编号。名称为原名称加“ 副本”，若重名则依次使用“ 副本 2”“ 副本 3”。复制一个副本时以该副本的完整名称为基础继续命名。

复制是**原位复制**，不改变任何坐标；副本与原对象最初完全重叠。状态栏会提示拖动箭头移开副本，也可直接修改右侧位置。重叠时可从左侧列表按名称明确选择原件或副本，视口单击不能区分完全重叠的表面。

建议验收顺序：

1. 选中长方体，修改尺寸和旋转，点击复制。核对新编号、名称、相同参数和自动选择。
2. 拖动副本或修改其位置，确认原件不变；圆柱体同样支持。
3. 撤销移动，再撤销复制，副本消失并重新选中原件；重做恢复同一编号和名称。
4. 删除列表中间的对象，撤销后检查对象回到原行、原参数及选中状态；再次重做删除。
5. 删除场景最后一个对象，视口只剩辅助显示；撤销可恢复对象。
6. 在属性输入框内选中文字并按 Delete，确认只删除文字，不删除场景对象。

未选择对象时两个按钮置灰，无操作也不增加历史。创建对话框、放置预览或拖动期间，复制和删除暂时禁用；先确认或取消当前操作。快捷键只在视口和场景列表中处理，长按产生的按键重复不连续复制或删除。属性输入中的 Ctrl+C、Delete 等文字操作不被接管。

按钮操作采用已提交参数；若仍有未提交的输入文字，执行时会刷新为当前场景数值。正常焦点移出触发的有效参数提交仍遵循既有规则。所有操作保留相机、临时预览角度和显示开关。删除不增加确认对话框，可以立即撤销。

## 复制和删除如何复用历史

每个 `SceneChange` 已支持可选的修改前、修改后参数：

```text
复制：before = 空，after = 副本参数
删除：before = 原对象参数，after = 空
```

复制先从所选对象完整拷贝业务参数，再生成不重名名称，调用 `Scene::add()` 分配新编号。记录副本在列表末尾的位置、原选择和副本选择，随后同步业务场景、渲染场景、列表及属性。

删除前保存对象参数和原列表索引。删除后选择设为 0。撤销删除调用 `Scene::restore()`，按原编号和原索引恢复对象，再选中该对象；重做再次删除。

所有新操作都经过 `recordApplied()`，所以在撤销后复制或删除会丢弃旧重做分支。编号分配器不随撤销回退：被放弃的副本编号不会分给另一个新对象。

## 快捷键与输入状态

`MainWindow::eventFilter()` 仅在事件来自视口、场景树或场景树内容区域时识别 Ctrl+D / Delete。快捷键覆盖事件先被接收，按键事件再执行操作；自动重复不执行。参数框仍保留自己的删除文字行为。

按钮和方法都检查是否有有效选择、是否正在创建或拖动。即使程序直接调用方法，也无法在拖动中途把对象删除。选择、创建模式及移动状态改变时会刷新按钮状态。

## 完全重叠副本的绘制

原位副本使用与原件相同的变换和几何。由于深度比较是 LESS，同一表面后画的对象可能无法覆盖先画的对象，导致选中副本却看不到金色高亮。

本轮先绘制选中对象，再绘制其余对象。完全相同深度的原件片元不会盖住已经绘制的选中副本；真实处于前方的其他模型仍按深度遮挡。没有关闭实体深度测试，也没有改变对象参数。

复制不新增专属基本体顶点缓冲，两个对象继续共用已有的长方体或圆柱体几何。删除移除场景中的绘制对象，不销毁这些共享资源。交换链与设备资源生命周期保持原有实现。

## 源码入口

1. `src/ui/MainWindow.cpp`：`duplicateSelected()`、`deleteSelected()`、按钮状态及限定范围的快捷键。
2. `src/ui/Ribbon.cpp`、`src/ui/RibbonIcons.h`：模型页入口与图标。
3. `src/scene/SceneHistory.h`、`src/scene/Scene.h`：现有历史回放和按编号、列表索引恢复对象。
4. `src/render/VulkanViewport.cpp`：选中对象优先绘制。
5. `src/ui/ObjectActionsCheck.h`：复制独立性、历史、快捷键、空场景和显卡图像检查。
