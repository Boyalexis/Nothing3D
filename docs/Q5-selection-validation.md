# Q5 单选与高亮验证记录

验证日期：2026-09-08。环境沿用 Qt 6.10.3、MSVC 2022、Vulkan SDK 1.4.357.0。

## 构建及自动测试

`scripts/test.bat`：Debug 构建成功，4/4 测试通过。

- `scene_picking`：最近表面而非插入顺序、不同对象缩放下的命中距离、删除后的后方对象、圆柱侧面和顶盖、外接方框空角、局部及预览旋转、位移、非均匀缩放、150% 坐标等价、宽视口、空白与越界坐标、零尺寸视口、不可逆矩阵、近远裁剪及实体内部相机。
- `scene_objects`：Q4 对象身份、参数校验、独立性和几何变换。
- `camera_math`：原有相机、投影、基本体与辅助线。
- `m0_smoke_test`：无显卡界面启动。

## 实际窗口及显卡验证

执行 `scripts/test-gpu.ps1 -Rounds 1`，每块显卡一轮：

| 显卡 | 连续帧 | 交换链代数 | 含退出阶段验证错误 | 结果 |
| --- | ---: | ---: | ---: | --- |
| Intel UHD Graphics | 416 | 4 | 0 | PASS |
| NVIDIA GeForce RTX 4060 Laptop GPU | 393 | 4 | 0 | PASS |

原有 Q3 导航、窗口缩放、最小化恢复、辅助线、方向立方体和功能区回归，以及 Q4 场景切换与删除读回检查均通过。

Q5 在真实窗口发送鼠标和键盘事件，并检查选择编号、场景列表、参数文字及实际 GPU 图像：

- 点击长方体、圆柱体及左侧名称，三处状态一致。
- 轻微手抖仍选择对象且不移动相机；拖远再回到起点不会误选。
- 中键、方向立方体、Home 不改变选择；方向立方体区域不会穿透拾取。
- 点击空白及视口 Esc 清空选择。
- 预览旋转后的点击命中正确；窗口调整后选中状态和高亮保持。
- 六对象场景能查看第六个对象的参数；替换场景、删除所选对象及空场景取消旧选择；无效编号不保留。
- 六组画面与 CPU 面色和遮挡参考一致：长方体高亮、圆柱体高亮、取消选择、旋转后高亮、窗口调整后高亮、六对象中的单体高亮。

人工查看了长方体高亮、六对象高亮及窗口界面截图：选中对象颜色明显变化，原面色差异和遮挡仍保留；右侧操作说明无溢出。窗口 QWidget 截图只用于检查界面，嵌入的原生 Vulkan 画面使用独立读回截图检查。
