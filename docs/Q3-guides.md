# Q3 补充：无限网格与方向立方体

## 当前效果

- XZ 地面不再有原来 10 m × 10 m 的固定边界；平移后网格继续延伸。
- 网格保持世界坐标对齐，采用 100 mm、1 m、10 m 三层线。细线随像素密度渐隐，远处按距离淡出，避免所有小格挤成一片。
- X 红、Y 绿（向上）、Z 蓝。X/Z 轴由地面着色器绘制；Y 轴按当前视锥裁剪无限世界直线，取消原来的 3 m 长度限制，向正负方向延伸到可见范围边界。模型会遮住位于其后的辅助线。
- 右上角改成参考图中的方向立方体样式：浅蓝灰色面、TOP / BOTTOM / FRONT / BACK / LEFT / RIGHT 名称、方位环及 N/E/S/W 标记。
- 点击右上角小房子：停止模型自动旋转，恢复初始相机、观察中心与模型角度。
- 方向立方体随相机绕转，但不随相机平移、缩放或模型自转。窗口缩小时控件区域也受边界约束。

未实现：网格吸附、显示开关、点击立方体面切换视图、立方体拖拽导航。方位约定为北=-Z、东=+X，FRONT 位于 +Z 面。

## “无限”如何实现

不是生成无限条线，也不是引入 Godot。现有 Vulkan 渲染器绘制一个覆盖屏幕的三角形，每个片元根据逆观察投影矩阵构造射线，与 Y=0 平面求交。着色器用交点的世界坐标计算网格及 X/Z 轴颜色。

平行地面、交点在视点后方或超出裁剪范围的片元被丢弃。有效交点重新计算真实深度，使网格与模型的前后遮挡正确。像素导数用于平滑线边缘及控制细线密度；颜色再与背景透明混合。

“无限”表示没有固定世界范围边框，并非数学上无限精度或无限可见距离。当前相机远裁剪为 100 m，网格在观察距离约 35–95 m 范围渐隐；大世界坐标精度管理尚未实现。

## 方向立方体如何绘制

立方体使用独立的小视口和正交投影，绘制前只清除该区域的深度。这样它覆盖主场景，但自身的面、文字与方位环仍能正确相互遮挡。

文字只在初始化时借助 Qt 字体栅格化，然后转成静态彩色小四边形并上传 Vulkan。所有元素都由 Vulkan 显示，读回截图包含整个控件；当前方案便于学习，但不是经过优化的字体图集方案。Home 图标也是几何，不是外部图片。

## 代码入口

- `shaders/grid.vert` 与 `grid.frag`：地面交点、深度、分层网格与渐隐。
- `src/render/ColorMesh.cpp`：网格专用管线、透明混合，以及 128 字节矩阵推送。
- `src/render/ViewCubeGeometry.h`：立方体、面文字、方位环和 Home 图标。
- `src/render/VulkanViewport.cpp`：绘制顺序、角落深度隔离及 Home 输入。
- `src/render/InfiniteAxis.h`：将竖直世界轴裁剪到视锥，保留正确深度，避免简单加长端点后穿过相机造成异常。
- `src/render/GuideGeometry.h`：布局/方向矩阵辅助函数；旧有限网格与线轴几何保留作历史学习参考，不再用于当前显示。

## 验证

基础测试继续覆盖相机、模型几何、方向矩阵和小视口边界。网格两个着色器通过 Vulkan 1.0 SPIR-V 静态校验。

GPU 图像检查覆盖模型最近表面颜色、网格背景混合、当前可见的方向立方体面、文字、环及 Home 图标，并测试相机绕转/缩放、模型自动旋转、窗口缩放、最小化恢复、重置和退出。另将观察中心移动到 (50, 0.75, 50) m，检查原网格范围之外仍有网格，再发送鼠标事件验证 Home 复位。

检查为有限视角和采样回归，不代表所有视角或设备上的完整证明。

2026-09-06 最终结果：Debug 构建及 2/2 基础测试通过；Intel UHD 三轮为 398 / 389 / 388 帧，RTX 4060 Laptop 三轮为 372 / 375 / 372 帧，全部 PASS。每轮经历 3 代交换链，含退出阶段的 Vulkan 验证错误为 0。帧数用于持续绘制检查，不是性能基准。报告与截图在 `build/q3-*`。
