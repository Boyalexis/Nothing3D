最终复核日期：2026-09-12。环境：Qt 6.10.3、MSVC 2022、Vulkan SDK 1.4.357.0，当前浅色界面布局。

## 构建与自动测试

`scripts/test.bat`：Debug 构建成功，**14/14 测试通过**。保留既有 Qt 私有模块版本绑定提示。

`scene_file` 覆盖：

- 两种基本体、中文及转义名称、毫米位置、多圈旋转的精确往返。
- 超过 JSON 双精度整数精确范围的编号，以及删除后的编号分配器恢复。
- 空场景和 1000 个对象的序列化；这不是渲染性能验收。
- 错误 JSON、根类型、版本、单位、未知字段、重复编号、无效参数、错误向量和过大文件被拒绝。
- 中文文件路径、读取失败、写入失败、编码失败后保留原文件。
- 历史保存点、撤销/重做返回保存点、新分支不能误判为已保存。

`project_editor` 覆盖：

- 保存提交属性框中有效的待输入数值；成功后更新路径和标题标记。
- 保存失败保留未保存状态、当前路径和先前文件。
- 打开损坏文件保留当前场景、选择和历史。
- 未保存提示中的保存、不保存、取消；取消打开和关闭不会丢失当前工程。
- 保存后打开同一文件读到最新数据；打开另一文件清空选择和历史。
- 取消切换示例恢复原下拉选项；明确不保存后才替换场景。
- 首次保存时取消文件选择，中止原来的打开操作。
- 空场景、删除后的编号分配器、另存路径及原文件保留。

原有对象操作、历史、移动、放置、属性、拾取、场景、相机、启动和布局检查继续通过。
