# Q3 验证记录

## 构建和基础测试

MSVC Debug 构建通过，`scripts/test.bat` 的两项测试通过：无显卡界面烟雾测试与相机/几何测试。检查包括相机方向、观察矩阵、透视裁剪范围、缩放和俯仰限制、平移与重置，以及长方体三角形数量和非退化性。

## 真实 GPU 回归

使用 `scripts/test-gpu.ps1 -Rounds 3`，集显和独显各运行三轮。

| 显卡 | 第一轮帧数 | 第二轮帧数 | 第三轮帧数 | 各轮交换链代数 | 含退出的验证错误 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Intel UHD Graphics | 320 | 338 | 349 | 3 | 0 |
| NVIDIA RTX 4060 Laptop GPU | 319 | 320 | 321 | 3 | 0 |

六轮全部 PASS。每轮覆盖连续绘制、窗口缩放、最小化恢复、图像读回、资源销毁，以及程序发送的鼠标绕转、滚轮缩放、自动旋转和 F 重置事件。此处帧数仅证明持续绘制，不是性能基准；自动输入不代表已经做过真实鼠标手感验收。

每轮在初始视角、改变相机并缩放窗口后、模型旋转后三个状态检查图像，最后再检查重置后的图像。CPU 参考检查器投影十二个三角形，对采样点求最近表面并比较面颜色，同时检查背景，包含前后表面重叠样本。因此检查不只判断“画面不为空”，也覆盖深度遮挡。检查是离散采样，不代表逐像素完整正确性证明。

输出为 `build/q3-gpu-test.txt`、逐显卡逐轮报告、验证日志及 `build/q3-viewport.png` 等截图。

## 范围与限制

- 单个固定长方体，不是参数化场景编辑器。
- 同步适配保持 Qt 6.10.3 版本锁定，详见 Q1 验证记录。
- 目前只在上述两张显卡和当前驱动上验证，不覆盖其他操作系统或独立呈现队列等环境。
- 严重 Vulkan 初始化失败仍沿用学习阶段的退出策略，尚未实现设备丢失恢复。
