# Q6 复制与删除验证记录

验证日期：2026-09-10。环境：Qt 6.10.3、MSVC 2022、Vulkan SDK 1.4.357.0。

## 构建与自动测试

`scripts/test.bat` 最终 Debug 构建成功，**11/11 测试通过**，无新增 C++ 编译警告，保留既有 Qt 私有模块版本绑定提示。

新增 `object_actions` 无显卡界面测试，通过模型页按钮、场景树键盘事件和参数框事件检查：

- 无选择时按钮禁用，直接调用操作也不修改场景或历史。
- 长方体和圆柱体均能复制完整位置、旋转和尺寸，生成新编号、新名称并自动选中。
- 修改副本不影响原对象；撤销副本编辑和复制后恢复原选择，重做恢复原副本编号和数据。
- 反复复制同一原件使用不重名后缀，新复制会替换旧重做分支；按键自动重复不生成额外对象。
- Delete 删除副本、清空选择；撤销和重做正确恢复/移除副本。
- 删除六对象场景中间的对象，撤销恢复准确的列表索引、数据和选择。
- 业务场景、列表条目顺序及名称保持一致。
- 在属性框内 Delete 修改文字，原对象和历史不变；测试保留控件自身的 mm 单位后缀。
- 删除最后一个对象得到空场景，撤销完整恢复；放弃的副本编号不被重新使用。
- 切换场景清空历史及选择，并重置按钮状态。

原有十项测试继续通过。
