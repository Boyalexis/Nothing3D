# 参考图界面实现

界面采用参考图的浅色蓝灰主题和桌面工作区布局：项目标题与搜索、分组功能区、左侧快捷栏、项目浏览器、真实 Vulkan 三维视图、右侧属性与底部命令窗口。沿用 Nothing3D 名称和中文操作标签。

首页提供打开、保存、另存为、导航、撤销重做、基本体创建与面板入口；模型、视图和工程页保留现有操作。未实现的管道、结构设计、碰撞分析等业务没有伪装成可用按钮。参考图的工厂模型没有作为背景图片替代三维编辑器。

项目搜索支持名称过滤和清除，Ctrl+Q 聚焦搜索。命令窗口支持 help、select、pan、zoom、fit、box、cylinder、copy、delete、undo、redo；不可用及未知命令给出反馈。水平、垂直分隔条可调整面板；窄窗口的功能区可横向滚动。

验证：Debug 构建成功，14 项 CTest 全部通过，含 ui_layout 的搜索、复制撤销、未知命令与 960×600 布局检查。实际 NVIDIA Vulkan 运行预览见 build/ui-preview.png。可用 --ui-preview 启动后自动截图并退出。
