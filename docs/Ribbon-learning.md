# 第一版可操作功能区

顶部使用 Qt Widgets 的 QTabWidget，分为首页 Home、模型 Model、视图 View、工程 Project。不依赖外部 Ribbon 或三维引擎库。

## 操作

- 工程 Project：打开、保存、另存为（Ctrl+O / Ctrl+S / Ctrl+Shift+S），详见 [工程文件说明](Q6-files-learning.md)。创建或拖动期间暂时禁用，离开未保存场景会提示。

- 首页：选择旋转、平移或缩放视角后，在视口内按住左键拖动。缩放模式向上拖动拉近。模式互斥，高亮按钮表示当前模式。
- 中键旋转、Shift + 中键平移、滚轮缩放保持可用，不依赖当前左键模式。
- 重置视图恢复相机和演示组姿态，停止自动旋转；保留左键模式和显示开关。
- 自动旋转按钮与视口空格/F、Home 复位后的状态保持同步。
- 首页编辑历史：撤销 / 重做按钮对应 Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z），悬停显示下一条操作类型；无历史或正在创建、拖动时置灰。支持创建、属性编辑与整次移动，详见 [Q6 编辑历史说明](Q6-history-learning.md)。
- 模型：长方体和圆柱体创建入口已开放。输入尺寸后，移动鼠标查看线框预览，在 Y=0 地面单击放置；Ctrl 按 100 mm 网格吸附，Esc 或“取消放置”退出。详见 [创建放置说明](Q5-creation-learning.md)。放置期间自动预览旋转暂时禁用。
- 模型页“所选对象”：原位复制、删除，支持撤销/重做。视口或列表快捷键为 Ctrl+D / Delete；未选中或正在创建、拖动时置灰。详见 [复制与删除说明](Q6-object-actions-learning.md)。
- 视图：网格、全部世界轴、方向立方体、移动手柄可独立切换。关闭网格不会关闭轴；关闭轴也不会关闭网格。方向立方体隐藏时，其 Home 点击区域一起禁用。移动手柄只在选中对象且未进入创建预览时显示，隐藏会取消当前拖动。
- 选中后拖动红 / 绿 / 蓝箭头修改世界 X / Y / Z，Ctrl 吸附 100 mm，Esc 或右键恢复起点；箭头以外的区域仍执行首页导航模式。拖动期间自动旋转暂时禁用，详见 [移动手柄说明](Q5-move-learning.md)。

导航模式与显示开关当前仅在本次运行有效，不保存到工程或用户配置；场景对象可保存到 .n3d 文件。传统的文件、编辑、视图、帮助菜单栏已移除，只保留自定义功能区；系统标题栏及窗口关闭按钮不变。

## 源码入口

- `src/ui/Ribbon.cpp`：Tab、分组、QAction、QToolButton 和事件连接。
- `src/ui/RibbonIcons.h`：Qt 绘制的高对比矢量风格图标，图标位图按 2 倍密度生成。
- `src/render/VulkanViewport.h`：左键导航模式、四个显示状态及拖动状态。
- `src/render/VulkanViewport.cpp`：应用导航模式，根据显示状态选择绘制路径。
- `src/render/ColorMesh.cpp` 与 `shaders/grid.frag`：通过管线专用常量预建“网格+轴、仅网格、仅轴”三种变体。切换按钮不需要重新编译着色器或新建管线。
- `src/ui/RibbonCheck.h`：通过实际工具按钮测试三种导航模式、创建入口启用、旋转复位状态及八种显示组合，读回图像验证变化。
- `src/ui/CreationCheck.h`：通过尺寸对话框和视口事件验证创建、预览、吸附、取消以及新对象编辑。
- `src/ui/MoveCheck.h`：验证手柄开关、三轴拖动、实时同步、吸附、取消和手柄像素。

学习重点：QAction 表达操作和状态，QToolButton 展示它，QActionGroup 保证导航模式互斥，信号与槽把 UI 状态传给视口。改变显示状态后必须请求重绘；按钮亮了不等于渲染代码已经执行。

验证包括构建与基础测试、双显卡实际绘制、窗口缩放和最小化恢复。界面截图 `build/ribbon-home-top.png` 只截功能区；QWidget 整窗截图不能可靠包含原生 Vulkan 子窗口，三维图像另由 viewport->grab() 检查。自动检查不替代所有 DPI 和人工操作手感验收。
