# Q2 验证记录

环境：Qt 6.10.3、MSVC 2022、Vulkan SDK 1.4.357.0，显式声明 Vulkan 1.0，着色器编译目标为 Vulkan 1.0。

| GPU | 三轮帧数 | 每轮交换链创建次数 | 验证错误（含退出） |
|---|---|---|---|
| Intel UHD | 342 / 343 / 343 | 3 | 0 / 0 / 0 |
| RTX 4060 Laptop | 335 / 336 / 337 | 3 | 0 / 0 / 0 |

每轮检查：实际显卡类型、验证层开启、至少 100 帧、缩放和最小化恢复、GPU 图像读回、RGB 三个角部区域、中心混合色、背景颜色，以及正常退出。六轮进程退出码均为 0。

首次测试图像正确，但出现着色器能力版本检查错误；将 QVulkanInstance API 版本显式设为 1.0 后重跑上述六轮，全部通过。

基础 Qt 烟雾测试还检查纯色图像不能通过三角形图像断言。两个编译后的 SPIR-V 文件通过 SDK 的 `spirv-val --target-env vulkan1.0`。

查看图像：`build/q2-viewport.png`；每轮报告及日志：`build/q2-intel-1.txt`、`build/q2-intel-1.log` 等。

限制：当前是单个平面三角形，资源分配或管线创建失败会报告错误并终止程序，尚未实现运行中恢复。没有进行大模型性能评估。沿用 Q1 的 Qt 私有同步适配器和版本锁定，尚未覆盖独立图形/呈现队列硬件。
