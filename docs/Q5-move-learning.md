# Q5 第五个小目标：三轴移动手柄

> 后续更新：创建、属性编辑与整次拖动已支持撤销/重做，见 [Q6 编辑历史说明](Q6-history-learning.md)。下文保留本小目标完成时的记录。

本轮将右侧的位置编辑扩展到视口。选中长方体或圆柱体后，底面中心出现 X 红、Y 绿、Z 蓝三个箭头。拖动箭头只改变对应的世界坐标，尺寸和对象旋转保持不变。

## 运行与验收

双击 `scripts/run.bat`。也可以用 `scripts/run.bat --integrated` 请求 Intel 集显。

1. 点击模型或左侧名称，查看底部中心的三个箭头；悬停在箭头上会改变颜色和光标。
2. 按住左键拖动一个箭头。右侧位置实时更新，另外两个坐标保持原值；松开左键保留结果。
3. 拖动时按住 Ctrl，将当前轴的**绝对坐标**吸附到最近的 100 mm。例如 X 从 -1600 移到约 -1363 mm 时，Ctrl 得到 -1400 mm。另两轴不吸附。松开 Ctrl 恢复自由位置，无需再次移动鼠标。
4. 拖动过程中按 Esc 或右键，恢复按下鼠标前的对象状态并保留选择。继续按着左键移动也不会转动相机，松开后可重新操作。
5. 修改右侧旋转角度，再拖动手柄：箭头仍表示世界 X/Y/Z，不随对象的局部旋转改变轴向。Y 轴允许对象离开地面，也允许负值。
6. 在“视图 View”页关闭“移动手柄”，箭头消失，左键拖动均按首页选定的导航模式处理；重新打开可继续移动。

手柄优先处理左键拖动；其他区域仍支持单击选择、拖动导航。中键导航和滚轮缩放在普通状态下保持可用；正在拖动手柄时冻结相机，避免改变拖动参考。方向立方体及 Home 保持独立的点击区域。

拖动时属性框显示实时值，暂时不可编辑，松开或取消后恢复。切换对象、切换场景示例、启动创建、隐藏手柄、重置视图、视口失焦、调整大小或失去鼠标捕获都会取消当前拖动。创建预览期间不显示手柄。

开始拖动会停止场景自动预览旋转，但保留当前预览角度和相机，因此画面不会跳回初始状态。取消后不自动恢复旋转。对象自己的旋转参数不受影响。

## 从二维鼠标到单轴位移

移动分成两个独立问题：**选中哪根轴**，以及**沿该轴移动多少**。

`MoveGizmo::layout()` 用选中对象的位置建立底心平移矩阵，再根据透视深度和视口高度确定箭头大小。箭头长度在屏幕上约为 96 个逻辑像素，透视缩短会使朝向镜头的轴更短。绘制与命中使用相同布局，窗口缩放和高分屏不会把点击位置与箭头分开。

`hit()` 将三根轴投影到屏幕，比较鼠标到线段的距离，采用 9 个逻辑像素容差。共享的中心留给普通对象拾取；近乎正对镜头、投影长度不足 14 像素的轴不显示，避免难以控制的拖动。底心在视口外或可见深度范围外时隐藏手柄，可平移相机找回对象。

鼠标按下后，`MoveGizmo::begin()` 保存本次拖动的逆投影矩阵、窗口尺寸、对象原位置和选中轴。它建立一个经过底心、包含该轴、尽量面向相机的固定平面：

```text
axis = 选中世界轴的单位向量
viewDirection = 穿过底心的鼠标射线方向
normal = normalize(viewDirection - axis * dot(viewDirection, axis))
```

每次鼠标移动时，把屏幕位置反投影成射线，与这个固定平面相交，再取交点在选中轴上的分量。减去鼠标按下时的分量，即得到位移。交点以米计算，写回场景前乘以 1000 转成毫米。

所有结果都从**原始位置 + 本次总位移**计算，不逐帧累加。因此按下箭头不会跳到箭头端点，往返拖动不会累计误差，Ctrl 的按下与松开也能重新计算正确位置。结果须为有限数且不超过场景每轴 ±1,000,000,000 mm 的范围；无效射线保留上一次有效结果。

当前采用世界轴。用于计算和绘制的矩阵包含场景的临时预览旋转，因此该预览旋转也不会造成鼠标和箭头错位；对象自己的尺寸与旋转不参与手柄轴向计算。

## 一次拖动的状态与同步

```text
浏览 → 按下箭头 / 保存快照 → 拖动 / 同步临时位置 → 松开 / 保留结果
                                   ↓
                              取消 / 恢复快照
```

`VulkanViewport` 在拖动中更新自己的渲染场景，并发出 `objectMoved`；`MainWindow` 更新业务场景、列表提示和属性值。属性刷新使用信号阻断，避免写回视口而形成反馈循环。这里不走普通属性编辑的 `updateObject()` 路径，因为外部编辑会取消当前手势。

取消会通过同一信号恢复起点快照，再释放鼠标捕获。取消后剩余的左键事件会被消费，防止突然变成相机拖动或模型单击。切换场景时先取消旧对象拖动，再替换场景，旧快照不会写进新场景。

目前只支持取消**正在进行**的拖动，松开后的操作尚无撤销。Q6 的命令系统将把一次完整拖动作为一个可撤销操作，而不是把每个鼠标移动都记成命令。

## Vulkan 生命周期

- **创建资源**：三个箭头由八边形杆和锥形箭头组成，作为一个不变的顶点缓冲上传；每根箭头占一个连续绘制范围，复用现有颜色着色器。
- **创建交换链管线**：手柄关闭深度测试和深度写入，确保位于模型内部的底心手柄仍可操作。
- **每帧绘制**：先绘制场景、网格和创建预览，再绘制手柄，最后绘制方向立方体。每根轴使用同一布局矩阵，悬停或拖动轴通过已有的金色混合参数突出显示。鼠标移动不重建顶点缓冲。
- **销毁**：交换链重建时释放手柄管线；设备资源释放时释放顶点缓冲，与已有网格的生命周期一致。

## 源码阅读顺序

1. `src/render/MoveGizmo.h`：手柄布局、屏幕命中、固定平面求交和箭头几何。
2. `src/render/VulkanViewport.h/.cpp`：手势状态、鼠标优先级、快照恢复和覆盖绘制。
3. `src/ui/MainWindow.cpp`：两份场景同步、属性更新及全窗口 Esc 行为。
4. `src/ui/Ribbon.cpp`：“移动手柄”显示开关及拖动时的预览旋转状态。
5. `tests/move_tests.cpp`、`src/ui/MoveCheck.h`：数学检查和真实显卡上的画面、输入检查。
