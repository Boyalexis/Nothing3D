## 实际运行包验收

`out/Nothing3D-0.1.0-win64-20260913-210009.zip`，14,513,394 字节，Release x64。

从 ZIP 解压到 `out/package-check-20260913-210054`，逐文件核对 SHA-256。随后将 PATH 限制为 Windows 系统目录，清除 Qt 插件与 Vulkan 层环境路径。

- 六项检查：启动、尺寸、变换、撤销重做、复制删除、工程文件，退出码均为 0。
- 两次真实窗口：Intel 与 NVIDIA 分别启动、渲染并保存完整窗口截图，退出码均为 0。
- 人工检查独显截图：模型、网格、方向立方体、手柄、中文功能区和属性面板均显示正常。
- 报告 `build/package-check.json`；截图在解压检查目录的 build 子目录。

这证明包不依赖开发目录的 Qt PATH；未使用干净虚拟机或另一台电脑，因此不声称适用于全部 Windows 环境。GPU 预览是无开发验证层的启动检查；Vulkan 正确性证据来自单独的双显卡验证运行。

## 重复打包

```powershell
.\scripts\package.ps1
.\scripts\test-package.ps1
```

前者构建 Release，使用 windeployqt 收集 Qt 运行库，并复制 MSVC 运行库、示例和说明，生成独立时间戳目录、ZIP 与文件校验清单。后者从实际 ZIP 解压运行。

脚本中的 MSVC 运行库位置对应本机安装版本，迁移构建机器时需更新。Qt 固定为 6.10.3，与现有呈现同步代码的版本保护一致。

运行说明见 [开始使用](First-stage-run-package.md)，性能原始证据见 [性能验收](Q6-performance-validation.md)。
