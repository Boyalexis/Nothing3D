# Q5 创建与地面放置验证记录

验证日期：2026-09-08。环境为项目锁定的 Qt 6.10.3、MSVC 2022、Vulkan SDK 1.4.357.0。

## 构建及自动测试

`scripts/test.bat`：Debug 构建成功，7/7 测试通过，无新增 C++ 编译警告。保留既有 Qt 私有模块版本绑定提示。

新增 `ground_placement` 检查：

- 地面求交及米到毫米转换，Y 精确为 0。
- 正负 X/Z 按最近的 100 mm 网格吸附。
- 逻辑像素与 150% 缩放后的坐标得到一致结果。
- 视口外、零尺寸、非有限鼠标坐标、不可逆矩阵、平行射线拒绝。
- 地面在相机背后、近裁剪面之前或远裁剪面之后时拒绝。
- 两类共享预览线段数量和金色顶点颜色。

原有变换输入、尺寸输入、拾取、场景、相机及无显卡启动六项测试全部通过。

执行 `scripts/test-gpu.ps1 -Rounds 1`，每块显卡一轮：

原有全部 GPU 回归继续通过。新增创建流程在真实窗口发送输入事件并检查：

- 两个创建入口启用，取消对话框不创建对象。
- 输入自定义尺寸后开始放置，停止临时预览旋转但保留相机。
- 悬停出现线框，业务场景和渲染场景对象数量均不增加；线框图像与无预览状态不同。
- Ctrl 无鼠标移动时更新吸附预览；拖动、天空和方向立方体点击不创建。
- 一次单击只创建一个对象，独立编号、不重名名称、尺寸、地面底心和零旋转正确。
- 场景列表、自动选择及参数面板同步，已有对象不变；创建对象可继续改尺寸和拾取。
- 第二次创建圆柱体，负 X、正 Z 按 100 mm 网格精确吸附。
- Esc、取消按钮、切换对象或场景可靠结束放置，取消保留之前选择且不遗留对象。
- 离开视口隐藏预览，窗口调整后可恢复预览。
- 空场景和隐藏网格时也能正常放置。

长方体提交、圆柱体提交、空场景首次创建三组最终图像与 CPU 几何/颜色参考匹配。已人工查看尺寸对话框、线框预览和四对象场景截图，显示及控件布局正常。
