# Q5 第二个小目标：编辑所选对象的尺寸

单选打通了“找到对象”，本轮接上“修改对象”。长方体的宽、高、深和圆柱体的直径、高度现在可以输入，提交后模型立即更新。位置和旋转仍只读，创建、移动手柄以及 Q6 的撤销和保存不在本轮范围内。

后续更新：位置和旋转编辑已开放，当前操作见 [Q5 位置与旋转说明](Q5-transforms-learning.md)。下文保留尺寸编辑阶段的说明。

## 运行与操作

双击 `scripts/run.bat`，在视口或左侧列表选中对象。右侧显示对应尺寸输入框：

- 长方体：宽、高、深。
- 圆柱体：直径、高；深度输入框隐藏。
- 未选中或空场景：尺寸输入框隐藏且禁用。

输入新尺寸后按回车，或者移开输入框焦点应用。输入过程中保持原模型，便于完整输入数值。加减按钮立即生效，默认步长 100 mm；输入框已获得焦点时滚轮也可以调整数值，未获得焦点时滚轮交给属性面板滚动。

尺寸单位为 mm，可输入两位小数，范围为 0.01–10,000,000 mm。零、负数、非数值或超范围的输入被拒绝；无效的中间文本在结束输入时恢复原值。这个范围沿用场景数值边界，不表示当前相机能同时看清全部极端尺寸。

提交尺寸不会改变对象编号、名称、位置、旋转、当前选择、相机或预览旋转角度。模型围绕底面中心改变大小，同场景的其他对象保持原样。高亮、列表悬停参数与拾取范围同步更新。

## 建议验收步骤

1. 选中初始长方体，把宽改为 1200.25、高改为 2100、深改为 800。模型变窄、变高，底心仍在原点，圆柱体不变。
2. 选中圆柱体，把直径改为 1000、高改为 1700.50。圆柱体增粗、增高，底心仍在 (-1600, 0, 0) mm。
3. 调整视角后继续改高度，确认视角与选择保持。
4. 点击缩小前模型占据、现在已经空出的区域，确认不会命中旧轮廓。
5. 输入无效尺寸后结束编辑，确认恢复原值。切换对象、取消选择或切到空场景，确认旧输入不会写入另一个对象。
6. 缩小窗口，属性面板仍可访问；内容超出可用高度时支持滚动。

右侧场景示例是可重复加载的预设。切换示例会用预设替换整个场景并丢弃当前修改；当前尚无保存和撤销。

## 输入怎样到达模型

```text
DimensionSpinBox：输入、范围与小数校验
    ↓ 确认后的 valueChanged
MainWindow::commitDimension：只修改当前对象的当前字段
    ↓ Scene::update 校验并写入业务数据
VulkanViewport::updateObject：更新渲染快照中的同一编号
    ↓ requestUpdate
SceneGeometry：按新尺寸生成模型矩阵并绘制
```

`keyboardTracking=false` 让键入过程不逐字符修改业务数据。回车和失焦时 Qt 解释输入，数值真正变化才触发提交；按钮步进直接触发同一入口。没有额外用 `editingFinished` 再提交一遍，避免仅查看经过小数舍入的数值就改写原数据。

每次只更新一个尺寸字段，不从全部输入框回收参数。因此编辑高度时，宽和深的内部精度不会因显示为两位小数而损失。场景目前使用 float 保存尺寸，极大数值不能保证 0.01 mm 精度；显示精度不等于底层存储精度。

`refreshDimensions()` 在显示、隐藏和赋值前阻断三个输入框的信号，避免切换对象时的程序赋值或焦点变化触发错误提交。正常用户移开焦点会先应用当前对象的有效输入；程序直接替换选择时，尚未提交的文本可以被新对象数值覆盖，但不会写入新对象。

`setScene()` 仍用于完整场景替换并清除选择；新加入的 `updateObject()` 用于修改同一对象，保留选择和相机。尺寸变化后取消尚未完成的视口单击，下一次拾取读取新的尺寸。

## 显卡资源与代码入口

尺寸编辑继续复用 Q4 的单位网格。资源创建和销毁流程不变：设备初始化时上传共享顶点，交换链初始化时创建管线，释放回调中销毁对应资源。每帧按更新后的尺寸生成矩阵，不修改仍在使用中的顶点内存，也不因编辑新增缓冲。

- `src/ui/DimensionSpinBox.h`：尺寸范围、小数、提交时机和滚轮行为。
- `src/ui/MainWindow.cpp`：输入框布局、选择切换时刷新、单字段提交和列表参数更新。
- `src/render/VulkanViewport.cpp`：保留选择与视角的单对象快照更新。
- `src/ui/DimensionCheck.h`：真实输入事件、精度保护、模型截图和拾取变化测试。

运行 `scripts/test.bat` 执行五项自动测试；`scripts/test-gpu.ps1 -Rounds 1` 执行双显卡回归。结果见 [尺寸编辑验证记录](Q5-dimensions-validation.md)。下一小目标可接入所选对象的位置与旋转编辑。
