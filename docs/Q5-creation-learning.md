# Q5 第四个小目标：创建基本体并在地面放置

本轮开放模型页的长方体和圆柱体创建入口。先输入尺寸，再在 Y=0 地面预览并单击放置，创建后自动选中新对象。三轴移动手柄及 Q6 的撤销、保存仍是后续工作。

## 操作与验收

双击 `scripts/run.bat`，进入顶部“模型 Model”页：

1. 点击“长方体”或“圆柱体”。对话框分别提供宽/高/深或直径/高，单位 mm，沿用尺寸编辑的 0.01–10,000,000 mm 范围和两位小数输入。
2. 点击“开始放置”。移动鼠标到地面，可看到金色线框预览；底部状态栏显示底面中心坐标。此时还没有创建场景对象。
3. 左键单击确认，生成一个独立对象并退出放置模式。左侧列表追加名称，模型选中高亮，右侧立即显示可编辑的尺寸、位置与旋转。
4. 如需继续创建，再点击基本体按钮。当前每次确认只创建一个对象。

放置期间：

- **Ctrl**：将底心 X、Z 吸附到最近的 100 mm 网格坐标，Y 始终为 0。负坐标也适用；例如 (-1240, 0, 1260) mm 吸附到 (-1200, 0, 1300) mm。按下或松开 Ctrl 时，无需移动鼠标，预览即可更新。
- **Esc / 取消放置**：丢弃预览，保留已存在的对象及之前的选择。对话框中的“取消”也不会创建对象。
- **左键拖动、中键、滚轮**：继续导航，拖动不会误触创建。调整窗口后再次移动鼠标即可恢复预览。
- **天空、方向立方体或不可见深度范围**：没有有效放置点，不创建对象。光标提示无法放置，模式继续等待有效位置。
- **离开视口**：隐藏线框，仍保留待放置对象；切换选择、加载示例或启动另一种创建会取消当前放置。

开始放置时停止场景自动预览旋转并将其临时角度复位，保留相机视角和各对象自己的旋转参数。放置过程中“自动旋转”暂时禁用，便于按世界坐标定位。取消后不会自动恢复预览旋转。

网格仅是辅助显示，隐藏网格或在空场景中仍可放置。鼠标射线始终与 Y=0 平面求交，不吸附已有模型表面，也不做碰撞检测，因此允许对象重叠。新对象的旋转初值为 (0,0,0)°，可以在右侧继续修改。

建议先创建一个宽 650.25、高 1000、深 700 mm 的长方体，再创建直径 600、高 900 mm 的圆柱体，检查自由放置、Ctrl 吸附、取消和创建后参数编辑。相机不会自动缩放适配新对象，需要时可自行缩放或平移。

## 三个状态

```text
普通浏览 → 尺寸对话框 → 放置预览 → 确认并回到浏览
               ↓            ↓
              取消          取消
               └────不改变场景────┘
```

`CreationDialog` 仅收集参数。点击“开始放置”后，`VulkanViewport` 保存临时对象参数及可选预览位置。预览没有场景编号、不进入场景列表，也不会被拾取当作正式对象。

有效的左键短按结束时，视口先结束预览，再发出 `objectPlaced`。`MainWindow` 调用 `Scene::add()` 分配稳定编号，按类型生成当前场景内不重名的名称，例如“长方体 2”，随后追加列表条目、更新渲染快照并选中新编号。已有条目和相机保持原样。

创建是一次确认一次提交。程序不在鼠标按下或悬停时提前插入对象，所以取消、无效点及拖动都不会留下临时对象。切换示例仍是整体替换场景，会丢弃当前修改，当前尚无保存和撤销。

## 地面求交和吸附

`GroundPlacement::point()` 将逻辑像素位置反投影为可见深度区间的近端、远端两点，形成线段：

```text
P(t) = near + t × (far − near)
令 P.y = 0 求出 t，仅接受 0 ≤ t ≤ 1
```

平行地面的射线、相机背后、近裁剪面之前、远裁剪面之后及视口外的位置均无有效结果。得到的米制 X/Z 转为毫米；按 Ctrl 时分别按 100 mm 四舍五入，返回的 Y 精确为 0。鼠标位置与视口大小均用逻辑像素，因此显示缩放不需要额外重复换算。

方向立方体由视口输入层先拦截。普通场景拾取与地面放置是两个独立用途：浏览时查找最近的实体表面，放置时求地面交点。

## 预览的 GPU 生命周期

- **创建**：设备初始化时，现有单位长方体与圆柱体三角形生成对应线段顶点并上传一次；交换链初始化时创建线列表管线。
- **绘制**：只有有效预览位置才绘制金色线框，使用待创建对象的尺寸和底心矩阵。启用深度测试，关闭线框深度写入，已有实体可以遮挡它。线框包含三角网格对角线。
- **销毁**：交换链回调释放预览管线，设备资源回调释放共享线段缓冲。鼠标移动不重建顶点缓冲，正式创建继续复用 Q4 的共享基本体资源。

## 代码与测试入口

- `src/ui/CreationDialog.h`：尺寸输入及开始/取消按钮。
- `src/ui/Ribbon.cpp`：创建入口、取消按钮及模式提示。
- `src/render/GroundPlacement.h`：地面求交和 100 mm 吸附。
- `src/render/VulkanViewport.cpp`：预览状态、光标、导航、确认和取消。
- `src/ui/MainWindow.cpp`：编号与名称、列表追加、自动选择。
- `tests/placement_tests.cpp`：求交、裁剪、正负坐标吸附与预览线段范围。
- `src/ui/CreationCheck.h`：完整创建交互、预览截图和提交后的图像比对。

运行 `scripts/test.bat` 执行七项自动测试；`scripts/test-gpu.ps1 -Rounds 1` 执行双显卡回归。结果见 [创建放置验证记录](Q5-creation-validation.md)。下一小目标是三轴移动手柄。
