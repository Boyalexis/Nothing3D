# Nothing3D 第一阶段运行包

这是个人学习项目的 Windows x64 本地体验包，版本 0.1.0。解压到可写目录，双击 Nothing3D.exe 即可启动，不需要编译项目。显卡驱动需要支持 Vulkan；包内不安装或修改显卡驱动。

## 开始使用

1. 默认场景包含长方体与圆柱体，左键单击选择，右侧修改尺寸、位置和旋转。
2. “模型”页创建对象，移动鼠标预览，单击地面放置。Ctrl 按 100 mm 吸附，Esc 取消。
3. 拖动三轴手柄移动对象，Ctrl+D 复制，Delete 删除；快捷键在视口或场景树生效。
4. Ctrl+Z 撤销，Ctrl+Y 重做。“工程”页保存或打开 .n3d，未保存修改会在关闭前提示。
5. “视图”页切换透视、正交、顶视、前视和右视；F 重置视图。
6. 从程序“打开工程”选择 examples 中的文件，打开后自动显示整体。需要重新取景时，点击首页“显示全部”。

中键旋转、Shift+中键平移、滚轮缩放；也可在首页选择左键导航方式。
前视与右视无法确定 Y=0 地面落点，创建时切换顶视。相机与视图设置不保存到工程文件。

## 包内内容

- Nothing3D.exe、Qt 6.10.3 运行库、插件与 MSVC 运行库。
- examples：初始场景及生成的千对象示例。
- docs：分阶段操作、原理和代码入口说明。
- manifest.json：打包时文件的 SHA-256 校验值。
- build：自动检查的临时输出目录，正常编辑不依赖这里的数据。

不包含开发工具、Vulkan SDK 或自动更新程序。默认不关联 .n3d 文件，请从程序内部打开。
当前只支持单选、箱子和圆柱体；尚无管道、多选、层级、自动保存和外部工业格式导入。

该包用于本地体验，没有做全新 Windows 机器的兼容性验收；双显卡测试结果只代表开发机器。重新分发前还需独立整理第三方许可与发布流程。
