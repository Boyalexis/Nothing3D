# 圆柱体演示

青色圆柱体位于长方体左侧，直径 800 mm、高 1400 mm，底面中心为 (-1600, 0, 0) mm，Y 轴向上。相机、网格、方向立方体和复位操作保持不变；自动旋转现在作用于整个演示组。

圆周分为 64 段。每段侧壁由两个三角形组成，顶面和底面各增加一个三角形，共 256 个三角形。侧面使用固定的分段颜色变化帮助观察圆形轮廓，目前不是实时光照，也不是精确曲面建模内核。

几何代码在 `src/render/CylinderGeometry.h`。当前仍是固定演示，不支持创建、选中和尺寸编辑。

验证：Debug 构建、2 项基础测试通过；测试检查尺寸范围及三角形非退化性。GPU 图像参考检查扩展到两个物体，要求圆柱体存在并比较最近表面颜色。Intel UHD 与 RTX 4060 Laptop 各一轮通过，包含窗口缩放、最小化恢复、观察旋转、演示组旋转及退出，Vulkan 验证错误为 0。
