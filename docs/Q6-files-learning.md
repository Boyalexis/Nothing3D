# Q6 第三个小目标：工程保存、打开与未保存提示

本轮将内存中的场景保存为带版本号的 `.n3d` JSON 文件，并加入打开、另存为和离开当前工程前的未保存提示。文件适配层使用 Qt 的 JSON 和文件工具，业务场景仍不依赖 Qt 对象树。

## 运行与操作

双击 `scripts/run.bat`，切换到“工程 Project”页：

| 操作 | 快捷键 | 行为 |
| --- | --- | --- |
| 打开工程 | Ctrl+O | 选择 `.n3d`，校验成功后替换场景 |
| 保存 | Ctrl+S | 首次选择路径，以后写入当前工程文件 |
| 另存为 | Ctrl+Shift+S | 选择另一路径保存，并切换当前文件路径 |

可先打开仓库的 `examples/getting-started.n3d`，修改尺寸或移动对象，再另存为自己的工程。没有输入扩展名时，保存对话框补充 `.n3d`，覆盖已有文件由该对话框确认。

文件保存：对象列表顺序、编号、名称、形状尺寸、毫米位置、角度旋转，以及下一个可分配编号。对象删除后即使保存再打开，新对象也不会复用已删除对象的编号。

本版不保存选择、相机、显示开关、临时预览旋转或撤销记录。打开后清空选择和历史，停止临时预览旋转并恢复默认相机；若模型远离原点或很大，需要自行平移、缩放查看。初始场景和示例可直接保存；空场景也可保存。

## 未保存状态

标题里的 `*` 表示有已提交但尚未保存的修改。创建、复制、删除、属性修改和完成的拖动都会进入该状态；选择、相机导航和显示开关不算场景修改。

保存成功会记住历史中的保存点。撤销离开保存点会重新标记未保存，重做到保存点会清除标记；如果撤销后创建了新分支，即使历史步数相同，也不会误认为已保存。没有修改的初始场景或刚切换的示例视作干净基线。

打开有效文件、切换示例、关闭窗口之前，如有修改，会提供：

- **保存**：成功后继续；保存失败或取消选择保存路径时，中止原操作。
- **不保存**：明确放弃当前修改并继续。
- **取消**：保留当前场景；取消切换示例时，下拉框也恢复原选项。

保存会先提交属性框中有效的待输入数值；无效文字按输入控件原规则恢复。离开工程前也会先完成此类属性提交，因此取消关闭后可能保留刚提交的数值，且仍标记未保存。

创建对话框、放置预览和拖动期间，打开/保存按钮暂时禁用。关闭窗口或切换示例时先取消临时手势，再处理已提交场景的未保存提示。

## 格式版本 1

文件包含固定标识、版本、单位、编号分配器和对象数组。编号使用十进制字符串，避免较大的 64 位整数在 JSON 浮点表示中失去精度。

```json
{
  "format": "Nothing3D",
  "version": 1,
  "units": "mm",
  "nextObjectId": "2",
  "objects": [{
    "id": "1",
    "name": "长方体 1",
    "shape": {"type": "box", "width": 2000, "height": 1500, "depth": 1000},
    "positionMm": [0, 0, 0],
    "rotationDegrees": [0, 0, 0]
  }]
}
```

圆柱形状为 `{"type":"cylinder","diameter":800,"height":1400}`。位置和旋转必须各有三个数值，尺寸必须为正并符合现有业务范围。名称是 UTF-8 文本；名称不承担对象身份，编号才是历史和选择使用的标识。

读取会拒绝格式标识或版本不符、未知字段、缺失字段、未知形状、错误类型、重复或无效编号、编号分配器冲突和无效尺寸/变换。当前文件上限为 32 MiB、10000 个对象、单个名称 4096 个 UTF-8 字节。这是读取保护范围，不代表已完成对应规模的渲染性能验收。

## 防止失败破坏场景或原文件

`SceneFile::decode()` 在局部临时场景中完成全部解析和校验。失败会返回错误，当前场景、路径、选择和历史保持原样。只有有效候选文件才会触发替换前的未保存提示；提示过程中若执行了保存，会重新读取候选文件，保证“保存后打开同一个文件”读到的是刚保存的数据。

`SceneFile::write()` 先生成并校验完整输出，再用 `QSaveFile` 写入同目录临时文件，最后提交替换。禁用直接写原文件的后备路径；无法创建临时文件、写入不完整或提交失败时，不提前清除未保存标记，也不把当前路径改成失败的目标。

文件层只接收/返回 `Scene`，不操作窗口；`ProjectFiles.cpp` 负责对话框、提示、标题和场景切换。保存不会清除当前会话历史，重新打开会清除。

## 验收与源码入口

建议测试：修改后保存、关闭再打开；撤销/重做到保存点；保存后删除再打开并创建新对象；打开损坏文件；在未保存提示中分别选择保存、不保存、取消；首次保存时取消文件选择。

- `src/io/SceneFile.h`：JSON 编码/解码、完整文件校验与原子写入。
- `src/scene/Scene.h`：编号分配器的保存与恢复。
- `src/scene/SceneHistory.h`：保存点及新分支的未保存判断。
- `src/ui/ProjectFiles.cpp`：文件入口、关闭事件和未保存提示。
- `src/ui/MainWindow.cpp`、`src/ui/Ribbon.cpp`：属性提交、示例替换和工程页快捷键。
- `tests/file_tests.cpp`、`src/ui/ProjectCheck.h`：文件与界面测试。

验证记录见 [工程文件验证](Q6-files-validation.md)。当前为手动保存，不含自动保存、历史持久化、文件关联双击打开或多工程窗口。
