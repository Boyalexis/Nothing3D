# Q6 第一个小目标：撤销与重做

> 后续更新：复制与删除入口已加入并支持历史回放，见 [对象复制与删除说明](Q6-object-actions-learning.md)。下文保留本小目标完成时的记录。

本轮为已有的创建、尺寸编辑、位置/旋转编辑和三轴拖动加入编辑历史。Qt 负责按钮和快捷键，独立场景层保存操作数据并执行恢复，Vulkan 继续根据场景绘制。

## 操作与验收

双击 `scripts/run.bat`，使用首页的“撤销”“重做”按钮，或以下快捷键：

| 操作 | 快捷键 | 结果 |
| --- | --- | --- |
| 撤销 | Ctrl+Z | 恢复上一次已提交编辑之前的状态 |
| 重做 | Ctrl+Y 或 Ctrl+Shift+Z | 再次应用刚撤销的编辑 |

没有可用历史时按钮置灰，悬停提示下一步将撤销/重做的操作类型。

建议按以下顺序验收：

1. 选中长方体，将宽改为 1234 mm，再修改 X 位置、Y 旋转。连续撤销三次，应依次恢复旋转、位置、宽度；重做三次则恢复修改后的参数。
2. 创建一个圆柱体。撤销后它从场景和列表中消失，恢复创建之前的选择；重做后恢复原编号、名称、参数、列表位置和选择。
3. 拖动长方体的箭头，途中多次移动鼠标，然后松开。一次撤销恢复整个拖动的起点，一次重做恢复终点。
4. 撤销一次拖动后，重新拖动并按 Esc 取消。原来的重做仍然可用。
5. 撤销后提交另一项修改，旧的重做分支会被丢弃。
6. 切换右侧场景示例，历史清空，新场景不能撤回到上一个示例中的对象。

选择、相机导航、自动预览旋转和显示开关不进入编辑历史。撤销/重做会恢复操作对应的选择、列表和属性，保留当前相机、预览角度和显示开关。

尺寸或变换输入以一次有效的数值提交为一步：键入后回车或失焦应用；每次箭头步进或滚轮数值变化各为一步。相同数值和无效输入不创建记录。属性输入框中使用历史快捷键时，会先丢弃尚未提交的文字，再执行场景撤销/重做，不使用输入框自己的文字撤销。

创建对话框、放置预览和拖动进行期间，编辑历史暂时不可操作。请先确认或用 Esc 取消当前操作。取消的预览、取消的拖动、只有按下/松开而无位移的手柄操作均不产生有效记录。

## 场景历史的结构

`SceneHistory` 是不依赖 Qt/Vulkan 的 C++ 类。每条 `SceneChange` 保存一个对象的操作信息：

```text
操作说明、对象编号、修改前参数、修改后参数
原列表位置、操作前选择、操作后选择
```

创建的“修改前参数”为空，修改属性或移动则同时保存前后参数。每条记录只复制被修改对象的数据，不保存整个场景，也不保存 GPU 资源。

历史用一个数组和游标管理：游标之前是已应用操作，之后是可以重做的操作。撤销成功后游标减一，重做成功后加一。提交新修改会丢弃游标之后的旧分支；无变化的提交直接忽略，所以取消手势不会破坏重做。

恢复前会检查对象的当前数据是否符合记录预期。如果不一致则拒绝执行，避免把不属于该历史的场景静默覆盖。界面保证所有正式编辑都记录，并在整体替换场景时清空历史。

## 创建编号为何不能重新生成

撤销创建会删除对象，但不回退场景的编号分配器。重做通过 `Scene::restore()` 按原编号和原列表位置恢复对象，而不是再次调用 `add()`。

例如创建对象 3，撤销后再创建另一对象，新对象使用编号 4，旧重做分支被丢弃。编号 3 不会被分配给不同的新对象，避免选择和后续命令误指向另一对象。

恢复操作复用尺寸和变换校验，并拒绝无效编号、重复编号和无效列表位置。失败时不修改编号分配器。

## 实时拖动与正式命令

手柄拖动仍实时更新渲染场景和业务场景，保证画面及属性即时响应。`MainWindow` 在 `moveChanged(true)` 时保存起点，在 `moveChanged(false)` 时比较终点：

- 正常松开且数据变化：记录一条“移动对象”。
- Esc、失焦、窗口缩放等取消：视口先恢复起点，比较得到相同数据，不记录。
- 中间的多次鼠标移动：只刷新场景和属性，不进入历史。

因此连续十次鼠标更新仍只需要一次撤销。历史回放通过独立的界面同步路径重建列表、更新渲染快照和恢复选择，阻断刷新信号，避免把撤销本身又记成一次属性编辑。

## 源码阅读顺序

1. `src/scene/SceneHistory.h`：操作记录、游标、撤销/重做及分支处理。
2. `src/scene/Scene.h`：保留编号和列表位置的对象恢复。
3. `src/ui/MainWindow.cpp`：创建/属性/移动的记录时机，历史回放、属性快捷键与界面同步。
4. `src/ui/Ribbon.cpp`、`src/ui/RibbonIcons.h`：按钮状态、快捷键和图标。
5. `tests/history_tests.cpp`、`src/ui/HistoryCheck.h`：纯场景测试、界面测试和显卡回归。

本轮不新增 Vulkan 管线或缓冲资源；回放后的对象继续使用既有基本体资源和变换矩阵绘制。当前历史只保存在内存，尚无工程保存或未保存提示。复制与删除入口将作为后续小目标接入同一历史。验证见 [Q6 撤销/重做验证记录](Q6-history-validation.md)。
