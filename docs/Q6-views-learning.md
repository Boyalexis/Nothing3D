# 正交投影与标准视图

## 操作

运行 `scripts/run.bat`，打开“视图 View”页。

- 透视：默认模式，近大远小。
- 正交：保留方向和中心，同样大小的物体不会因远近改变显示大小。
- 顶视：从 +Y 向下看，屏幕向右为 +X，向上为 -Z。
- 前视：从 +Z 看，屏幕向右为 +X，向上为 +Y。
- 右视：从 +X 看，屏幕向右为 -Z，向上为 +Y。

标准方向自动使用正交，停止演示组旋转并归零预览角度。对象参数不变。
滚轮缩放、平移和旋转仍可用；旋转后成为自由方向的正交视图。
点击透视保留当前方向；按 F 或点击重置视图恢复初始透视相机。
切换模式时，目标平面上的显示比例保持一致，其他深度的物体会按投影规则改变显示大小。

## 编辑注意事项

对象选择和可见方向的移动手柄继续可用，Ctrl 按 100 mm 吸附。
正对观察方向的移动轴没有可辨认的屏幕长度，因此隐藏；可切换方向或使用属性面板编辑该轴。
顶视可在 Y=0 地面放置。前视和右视的视线平行于地面，无法确定地面落点；状态栏提示切换顶视或转向可见地面。
切换视图会取消正在进行的手柄拖动，恢复拖动前的位置。相机变化不记入对象撤销历史，也不写入 `.n3d`。

## 原理与代码入口

`src/render/OrbitCamera.h` 提供两种投影矩阵。正交可见高度为 `2 × distance × tan(22.5°)`，对应透视相机目标平面的高度；两种模式共用缩放范围和平移速度。
相机朝上向量由偏航角和俯仰角计算，顶视时朝向 -Z，避免固定世界 +Y 与视线平行导致矩阵退化。

`src/render/VulkanViewport.cpp` 处理视图切换和放置预览刷新；`src/ui/Ribbon.cpp` 提供按钮并同步投影选中状态。
拾取、地面交点和移动使用投影矩阵的逆矩阵还原近、远端点，因此同一套实现可支持两种投影。

## 手动练习

1. 建立两个相同尺寸、不同深度的箱子，比较透视与正交。
2. 顶视检查平面布局，前视检查高度，右视检查前后关系。
3. 顶视放置新对象，拖动 X/Z 手柄，按 Ctrl 检查 100 mm 吸附。
4. 前视尝试放置，确认出现不可放置提示；转到顶视再确认。
5. 切换正交后按 F，确认透视按钮重新选中。
