# Q6 撤销与重做验证记录

验证日期：2026-09-10。环境：Qt 6.10.3、MSVC 2022、Vulkan SDK 1.4.357.0。

## 构建与自动测试

`scripts/test.bat` Debug 构建成功，**10/10 测试通过**，无新增 C++ 编译警告；保留既有 Qt 私有模块版本绑定提示。

新增 `scene_history`（独立 C++ 场景测试）：

- 创建、修改的连续撤销与重做，恢复完整对象参数与选择编号。
- 空历史无操作；新修改截断重做分支，无变化记录保留重做。
- 撤销创建不回收编号，重做按原编号恢复；对象恢复保留原列表位置。
- 清空历史后无撤销/重做；非法参数、重复编号恢复被拒绝。
- 无效恢复不改变对象或编号分配器；历史与实际数据不一致时拒绝回放且不移动游标。

新增 `history_editor`（无显卡界面测试）：

- 尺寸、位置、旋转分别产生有效记录，按钮状态随游标变化。
- 切换选择后撤销，恢复实际编辑对象的选择与属性。
- Ctrl+Z 丢弃未提交文字并撤销已提交编辑，Ctrl+Y / Ctrl+Shift+Z 重做。
- 连续撤销恢复基线，选择与相同数值不破坏重做，新修改丢弃旧分支。
- 其他对象不变，切换场景清空历史。

原有八项三轴移动、地面放置、变换编辑、尺寸编辑、拾取、场景、相机和启动测试继续通过。
