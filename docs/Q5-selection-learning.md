# Q5 第一个小目标：单选、高亮与参数查看

Q4 建立了独立场景对象，本轮让用户能够选中其中一个对象。选择是编辑器状态，不改写对象的尺寸、位置或旋转。手动输入参数、点击创建、移动手柄仍是后续小目标。

后续更新：尺寸编辑已开放，当前操作见 [Q5 尺寸编辑说明](Q5-dimensions-learning.md)。下文保留单选阶段的实现说明。

## 运行和验收

双击 `scripts/run.bat`：

1. 左键单击长方体：模型显示金色高亮，左侧名称选中，右侧显示该对象的名称、尺寸、位置和旋转。
2. 单击圆柱体或左侧圆柱体名称：选择切换到圆柱体，长方体恢复原色。列表键盘导航也沿用 Qt 的单选行为。
3. 单击视口空白处，或按 Esc：取消选择，右侧提示未选中。窗口中的 Esc 快捷键也覆盖列表和示例选择框。
4. 按住左键拖动：仍按首页当前模式旋转、平移或缩放；拖动结束不会改变选择。小于系统拖动阈值的轻微手抖按单击处理。
5. 中键、Shift＋中键、滚轮照常导航。F 或方向立方体 Home 重置相机并停止预览旋转，保留所选对象。
6. 切到六对象示例，点击任意对象名称，右侧能查看该对象的参数。切换示例或整体替换场景会清空选择，防止相同编号被误认成原场景对象。

方向立方体区域拦截左键操作，不会选中它后面的模型。点击其面暂不切换观察方向。参数面板当前只读。

## 从二维点击找到三维对象

`src/render/ScenePicking.h` 使用当前相机矩阵和预览旋转的逆矩阵，把鼠标位置变成视锥近面与远面上的两个点。连接这两点，得到有效可见深度范围内的射线段。

坐标采用 Vulkan 的屏幕 Y 方向和 0–1 深度范围。鼠标位置与视口尺寸都用 Qt 逻辑像素，相除得到归一化坐标，因此不需要再给鼠标位置单独乘显示缩放倍率。

每个对象都用自身模型矩阵的逆矩阵，将射线段变换到单位基本体空间，再测试该基本体的全部三角形。长方体检测 12 个三角形；圆柱体检测与画面一致的 64 段封闭网格，包含顶底面。圆柱外接方框的空角不会被误选。

命中结果以线段参数 `t` 比较，取最近的表面。局部射线方向不能再归一化，否则不同尺寸对象的命中距离无法直接比较。只接受 `0 ≤ t ≤ 1`，排除近裁剪面之前、远裁剪面之后以及相机背后的表面。相机在实体内部时可以命中朝外的出口表面，与当前双面绘制规则一致。

当前使用逐对象、逐三角形的 CPU 检测，按单击运行，没有空间索引。尚未进行 1000 对象的拾取性能验收。

## 选择怎样同步

- `VulkanViewport` 在左键释放时完成拾取，保存对象编号并发出 `selectionChanged`。
- `MainWindow::selectObject()` 校验编号，再同步左侧单选和右侧参数；通过 `QSignalBlocker` 阻止列表更新反过来重复触发选择。
- 左侧名称被点击时也调用同一同步入口，视口按编号高亮。
- 编号 0 表示未选中；不存在的编号按未选中处理。整体场景替换会取消未完成的单击并清空旧选择。

左键按下先记录位置，移动超过系统阈值才进入导航。即使拖远后又回到起点，仍被视为拖动，不会误触发选择。中键和方向立方体操作不进入模型选择流程。

## 高亮与资源生命周期

`shaders/box.vert` 将选中对象的原面色与金色混合，保留面之间的色差。深度测试仍然开启，因此遮挡关系不变，高亮不会透过前方实体。

普通网格的 push constants 从 64 字节矩阵扩展为 80 字节：矩阵加一个 RGBA 高亮参数。每次绘制都写入本对象的参数，未选中的模型和方向立方体使用混合比例 0。网格着色器的 128 字节布局保持独立。

资源创建仍上传一次共享单位几何并创建管线；每帧只写矩阵和高亮参数；窗口调整和退出仍通过 Qt 的资源释放回调处理。选择切换不创建新顶点缓冲，也不修改 GPU 正在使用的顶点内存。

## 源码和测试入口

- `src/render/ScenePicking.h`：屏幕反投影、三角形相交和最近命中。
- `src/render/VulkanViewport.cpp`：单击与拖动区分、选择信号和逐对象高亮。
- `src/ui/MainWindow.cpp`：列表与参数查看同步、窗口 Esc 快捷键。
- `src/render/ColorMesh.cpp`、`shaders/box.vert`：高亮参数上传及颜色混合。
- `tests/picking_tests.cpp`：遮挡、圆柱空角、变换、坐标缩放、裁剪等数学测试。
- `src/ui/SelectionCheck.h`：真实窗口输入事件、同步检查与 GPU 高亮截图比对。

运行 `scripts/test.bat` 执行四项自动测试；运行 `scripts/test-gpu.ps1 -Rounds 1` 执行双显卡回归。结果见 [Q5 选择验证记录](Q5-selection-validation.md)。
