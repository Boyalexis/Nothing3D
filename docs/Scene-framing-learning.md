# 自动取景与显示全部

打开 .n3d 工程后，程序自动把全部对象放入画面。首页新增“显示全部”：在当前观察方向和投影模式下重新取景。空场景保持当前相机位置。

## 使用

1. 打开千对象示例，直接看到整体布局。
2. 平移到场景外，点击首页“显示全部”找回对象。
3. 切换顶视或正交，再点“显示全部”，观察方向保持不变。
4. 调整窗口大小后，如需重新留出合适边距，再点一次“显示全部”。

“重置视图”与 F 仍恢复默认相机；命令窗口原有 fit 命令仍对应重置视图。本轮新增按钮与原有重置入口分别保留。
显示全部停止演示旋转并归零预览角度，取消未完成的手柄拖动；已经提交的对象参数、选择、历史与工程保存状态不变。放置过程中会刷新预览位置。

## 原理

每个基本体的局部包围盒有 8 个角点。先应用该对象的尺寸、旋转和位置，再求全部角点的世界边界。以边界中心为相机目标，使用包住边界的球确定观察距离。

透视模式按较小的水平/垂直视角计算距离，正交模式按显示范围计算，并预留 12% 的半径余量。因此窄窗口也不会只顾高度而裁掉左右对象。圆柱使用保守包围盒，所以有时留白会比精确轮廓稍多。

取景后，缩放范围和近远裁剪面随场景尺度调整，支持超出旧 30 米缩放上限的布局。仍使用现有浮点矩阵；极端坐标下的数值精度限制没有在本轮彻底解决。

## 代码与验证入口

- `src/render/SceneFraming.h`：场景边界和相机距离。
- `src/render/OrbitCamera.h`：自适应缩放与裁剪面。
- `src/render/VulkanViewport.cpp`：交互状态与取景动作。
- `src/ui/ProjectFiles.cpp`：打开成功后的自动取景。
- `tests/camera_tests.cpp`：千对象与旋转对象，窄/宽比例、透视/正交、小/大尺度的全部角点裁剪检查。
- `src/ui/RibbonCheck.h`、`src/ui/ProjectCheck.h`：真实按钮与工程打开检查。
